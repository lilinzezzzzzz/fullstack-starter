## 2026-11-17 用固定 lazy_proxy 导出配置

配置模块删除模块级 **getattr**，通过标准库属性读取代理导出固定 settings 入口。代理本身不缓存目标，创建、from-import、repr 和布尔判断不调用 getter；get_settings() 首次实际取值时严格加载 TOML，并缓存真实 Settings。bind_settings(real_settings) 仅替换内部缓存、返回旧值，不替换公开代理；None 恢复未加载状态，代理和未校验字典不能作为绑定输入。load_settings(path) 继续独立加载，不读写缓存，不增加配置来源、默认值或环境字段覆盖。

所有 CLI 子命令先严格加载 --config 所选文件，再调用绑定接口；提前导入或已缓存其他文件时，公开代理仍保持身份且读取本次选择。测试统一通过绑定接口准备配置，自动 fixture 保存并在资源关闭后恢复缓存，包括空状态；不再替换模块 settings 或直接操作私有缓存。真实类型、身份及序列化使用 getter 或 loader 的真实对象，代理只支持属性读取，不转发赋值、删除、调用、迭代等协议。新增代理与缓存/绑定行为检查，更新导入、CLI、数据库、迁移和服务调用方测试；创建器增加 lazy_proxy.py 的必需源码与缺失拒绝检查，当前文档同步代理语义。
